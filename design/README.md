# design

I picked challenge A, the stable chassis. CAD files are in `cad/` and the CG maths is in `calcs/stability.md`.

The model has the chassis, four wheels, battery/controller blocks, a basic arm and a 50 mm cube. The cube centre is 70 mm ahead of the chassis front edge.

OpenSCAD is the editable source. STEP files are included as concept assemblies and STL is a mesh export. These are simplified and should not be treated as ready-to-print or final manufacturing files.
